  5. 若添加后无法播放，可能是该站线路为 token 加密型，本应用只能播放直链 m3u8 线路。

帮助

Help
v1.4.3
快速上手
三步开始追番
1
浏览分类

左侧「分类」进入，按年份 / 地区 / 类型筛选番剧。

2
搜索番剧

顶部搜索框输入番名 / 别名快速查找。

3
在线播放

详情页点击「立即播放」，可切换线路与选集。

使用说明
了解数据源、播放与设置
数据源

「设置 → 数据源」切换默认数据源；「设置 → 自定义数据源」可添加资源共享站。切换后首页与分类自动刷新。

播放

部分线路需要手动切换线路（详情页或播放页「切换线路」）。若需自动连播请在设置开启。

外观

「设置 → 界面外观」调整玻璃光效强弱或开启简洁模式，立即生效并自动保存。

常见问题
遇到的常见情况与解决办法
播放失败 / 画面黑屏

多为线路失效。请点击「切换线路」到另一条线路，或切换到其它数据源重试。

没有声音

可能是浏览器自动播放限制。请手动点击播放器内播放键，或在设置关闭「播放器自动静音」。

自定义源添加后无内容

请确认 API 地址返回的是 JSON（以 {"code":1,...} 开头）。若仍为空可能是该站接口不兼容。
