# Maoe

Maoe 是一款基于 Electron 开发的动漫轻小说聚合客户端，提供多数据源浏览、在线播放与小说在线阅读

## 功能特性

- 多数据源聚合：支持添加自定义源；可按分类、地区、年份、类型筛选内容
- 全量内容浏览：首页自动翻页抓取，展示全部动漫小说，无需逐页手动加载
- 在线播放：基于 hls.js 的播放器
- 版本更新：启动时自动检查更新，也可点击主界面左下角版本号手动检查，更新发布渠道
- 个性化设置：支持主题强调色自定义与玻璃光效开关

## 数据源说明

客户端内置多个动漫数据源以及轻小说源。部分数据源对 PC 端请求存在限制，客户端已做相应兼容处理，仅涉及公开数据的读取。

## 构建

前置要求：Node.js

```bash
npm install
npm run dist
```

构建产物位于 `dist/` 目录，文件名为 `Maoe-Setup-<版本号>.exe`。安装包为 64 位 NSIS 格式，提供中文安装界面，支持自定义安装目录并创建桌面快捷方式。

开发调试可使用：

```bash
npm start
```

## 目录结构

```
main.js         主进程：窗口管理、请求兼容处理、外部链接拦截
preload.js      预加载脚本
src/
  index.html    界面结构
  css/style.css 样式：玻璃效果与主题色变量定义
  js/
    app.js      界面逻辑：首页抓取、更新检查、播放控制
    api.js      数据源管理：内置源、自定义源、分页抓取
```
